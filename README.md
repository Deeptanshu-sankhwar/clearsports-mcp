# clearsports-mcp

MCP server for the [ClearSports API](https://clearsportsapi.com) — odds, scores,
schedules, injuries and player stats for AI agents, over one normalized JSON schema.

## Install

```bash
npx clearsports-mcp
```

Set `CLEARSPORTS_API_KEY` — get a key at https://clearsportsapi.com ($9 Tryout, key emailed after checkout).
